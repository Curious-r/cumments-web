cumments-web — SSG 黑盒 Dogfooding

站点： test-blog / hello-world @ https://comments.curious.host（0.28.1）
组件： <cumments-comments> via <script type="module">（preview API，不冻结）
手工用例：首次访问→自动 identity→加载→新建→202→pending→SSE→多标签→reaction→翻页→刷新→断线→恢复

示例文章（模拟静态站点 page）

此页模拟任意静态站点生成器（Zola/Hugo/Astro 等）生成的静态页，仅通过一个 script + 一个 custom element 接入评论。

Dogfooding 手工清单（14 项）
  1. 首次访问（清空 localStorage cumments_identity 后刷新）
  2. 自动 identity（应无 “identity required”）
  3. 加载已有评论
  4. 新建评论 → 202
  5. pending 提示
  6. SSE 实时 → pending 消失
  7. 多标签页同开
  8. reaction 加/移除
  9. 翻页
  10. 刷新后 identity 保持
  11. SSE 主动断开（DevTools Offline）
  12. SSE 恢复
  13. 恢复窗口内新评论是否到达/去重/乱序
  14. 长时间挂页观察
